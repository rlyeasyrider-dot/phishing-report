# Отчёт по фишинговой кампании

Учебный проект: автоматизация подготовки отчёта по результатам имитационной фишинговой рассылки.

## Что делает

- Генерирует тестовые данные (`generate_data.py`) — 500 сотрудников, 8 отделов, флаги opened / clicked / reported.
- Читает CSV с результатами рассылки (`report.py`).
- Считает метрики: **open rate**, **click rate**, **report rate** — общие и в разрезе отделов.
- Сортирует отделы по click rate — самые уязвимые сверху.
- Выгружает Excel с отдельными листами: «Сводка», «По отделам», «Динамика» (если передан второй файл).

## Зачем это нужно

В Security Awareness после каждой имитационной рассылки нужно готовить отчёт: где проседает безопасность, какие отделы самые уязвимые, как меняется динамика. Делать это руками в Excel — часы рутины. Скрипт сокращает подготовку отчёта до секунд.

## Стек

- Python 3.10+
- pandas — чтение CSV, группировка, расчёт метрик
- openpyxl — запись Excel с несколькими листами

## Установка и запуск

```bash
pip install -r requirements.txt

# 1. Сгенерировать тестовые данные
python generate_data.py

# 2. Построить отчёт
python report.py campaign_data.csv
